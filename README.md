# BARAKUDA Analysis Suite — Modular (Package root `barakuda`, Option A dropdown)

Run:
- `python main.py`

## Two-phase batch (mandatory gate)
- Select files in Dataset
- Set ROI in Preview (required for Optical Tweezers preview gate)
- Click **Preview Gate (mandatory)**
- Only if PASS, **Run Batch** becomes enabled

`Run Batch` orchestration is the next implementation step (device pipelines wired to shell).

## Devices
- Optical Tweezers: panel loaded (existing UI), preview gate can run a 1-frame tracking check
- AFM: placeholder panel
